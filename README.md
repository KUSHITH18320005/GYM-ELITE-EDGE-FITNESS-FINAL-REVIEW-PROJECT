# Gym Elite Edge Fitness Platform

## Project Overview

Gym Elite Edge Fitness Platform is a modern full-stack fitness management web application developed to improve user engagement and digital fitness experiences. The platform provides users with workout management, BMI calculation, membership handling, authentication, and contact support through a responsive and interactive web interface.

The project demonstrates the integration of frontend and backend technologies using React.js, Node.js, Express.js, and MongoDB to build a complete real-world fitness management system.

## System Architecture

The application follows a full-stack client-server architecture.

### Frontend Layer
The frontend is built using React.js and provides an interactive user interface for fitness management.

### Backend Layer
The backend is developed using Express.js and handles API requests, business logic, authentication, and database communication.

### Database Layer
MongoDB is used to store user details, membership information, workout data, and contact form submissions.
